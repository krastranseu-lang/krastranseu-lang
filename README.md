# Hi, I'm Illia

I'm building **Klyo**, with a focus on browser games and tools that help independent developers move from an idea to a tested, playable release.

My work includes the Klyo Games platform, a hosted MCP integration for game-development workflows, and practical examples of online multiplayer games. I also work on website-analysis tools.

## What I'm working on

- **Game publishing and iteration:** previews, diagnostics, release workflows and useful developer documentation.
- **AI-assisted development:** connecting an assistant to tools while keeping permissions and release decisions explicit.
- **Connected developer tools, in development:** exploring a workflow across VS Code, Google Chrome and Godot.

The product overview and project entry points live at [Klyo Games on GitHub](https://github.com/Klyo-Games). To try the platform, visit [Klyo Games](https://games.klyo.pl/).

I welcome reproducible bug reports, integration feedback and conversations with developers building for the browser.

## Projects

- [Klyo Games MCP](https://github.com/krastranseu-lang/klyo-games-mcp): connect an AI assistant to the Klyo browser-game publishing workflow.
- [Klyo Multiplayer Starter](https://github.com/krastranseu-lang/klyo-multiplayer-starter): a Four in a Row example with solo, local and online play.
